Harvard Processor

A parameterized, multi-cycle Harvard-architecture processor built from 12 coordinated RTL modules.

The processor follows a Harvard architecture: separate program and data memories, a custom instruction set, a hardwired control unit, and a multiplexer-based internal data bus. It's demonstrated at 8 bits but parameterized to any data width at instantiation. Twelve independent modules, the ALU, registers, program counter, ROM, RAM, memory address register, flags register, instruction register, T-state counter, and control unit, are coordinated through T-state sequencing into one multi-cycle datapath.

Amdahl's Law study: removing the MAR

An architectural study examined what happens when the Memory Address Register is eliminated from the datapath, letting memory be addressed more directly. Before the change, 84% of the ISA executed in 2 T-states; after it, 100% did, giving every instruction a uniform 2-cycle execution time. Amdahl's Law was used to validate the change.
