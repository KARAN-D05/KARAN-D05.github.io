High-Performance Multipliers

Four 32-bit multiplier architectures, compared by what actually matters: throughput.

This project extends the same question from the adder study to multiplication: four 32-bit architectures, Shift-and-Add (SHA), Braun Array (BAM), Wallace Tree (WTM), and Dadda Tree (DTM), characterized on identical terms using the Sky130HD standard-cell library. It also measures how the choice of final carry-propagate adder changes overall multiplier performance, reusing the adder IP from the project above.

Because these architectures use fundamentally different execution models, Fmax alone doesn't describe multiplication performance well. Shift-and-Add is iterative, spending 32 clock cycles per multiplication; the others are combinational, producing one result per operation. Throughput is measured directly to make the comparison fair.

Post-synthesis characterization, Sky130HD

All four results below use a 64-bit Kogge-Stone Adder as the final carry-propagate stage; a Ripple-Carry variant was also evaluated to isolate the effect of that final stage.

Dadda Tree reaches roughly 35× the throughput of Shift-and-Add for about 4.4× the area, the clearest area-for-speed trade in the set. It also beats Wallace Tree on both area and speed, since a Dadda reduction tree needs fewer partial-product reduction stages for the same operand width.
