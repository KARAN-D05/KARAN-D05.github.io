Hopfield Network

A binary Hopfield neural network in SystemVerilog, taken from RTL through synthesis to GDSII.

A Hopfield network is an associative memory: instead of retrieving data by address, it recalls a stored pattern from the content of a noisy or incomplete input, by repeatedly updating neuron states until the network settles into a stable configuration. This project implements one as a deterministic, synthesizable digital system, with connection weights generated by the Hebbian rule, and carries it through physical implementation to a final GDSII layout. It builds on the single neuron of the Artificial Neuron project, scaled to 25 interconnected neurons.

Implementation

  • Hebbian weight matrix, a predefined symmetric 25×25 matrix with zero diagonal entries, encoding a stored 5×5 pattern.
  • Bipolar neurons, where binary 1 represents +1 and binary 0 represents −1.
  • Sequential updates, one neuron per clock cycle in a fixed order, each according to its weighted inputs.
  • Convergence detection, stopping when a complete pass produces no state changes, with a configurable maximum pass count to prevent indefinite operation.

Physical implementation

Beyond synthesis, the design was taken through floorplanning, placement, clock tree synthesis, and global and detailed routing using OpenROAD and the Sky130HD standard-cell library, culminating in GDSII layout generation.

Verification

The implementation was verified at both the RTL and gate level: all 20 selected test inputs converged to the expected stored pattern in RTL simulation (20/20) and in post-synthesis gate-level simulation (20/20).

Toolchain: SystemVerilog, Icarus Verilog, Yosys, OpenSTA, OpenROAD, KLayout, GTKWave, Python (Hebbian matrix generator), Sky130HD
