Repeated Arithmetic Machine

A 4-bit feedback-driven computing machine, from a single self-correcting adder to a stored-program automaton.

This project began from a simple question: what if the output of an arithmetic operation could be fed back into its own input? The first prototype could only add and take feedback. Five versions later, the Repeated Arithmetic Machine (RAM) is a modular 4-bit system with feedback-driven control, automatic error correction, and the ability to execute programs stored in memory. It's the hardware root the rest of this work builds on, the point where the project crossed from circuits into a programmable system.

Evolution

  • V0, proof of concept: a single feedback-driven adder.
  • V1, manual arithmetic logic and two's complement handling.
  • V2, a low level of automation added to the control path.
  • V3, self-correction, state-based control, and a high level of automation.
  • V4, sequential execution of instructions stored in memory.

The instruction set was not designed on paper first. It emerged from the machine's own hardware primitives, addition, subtraction, feedback correction, fault recovery, reset, and was mapped to assembly only afterward. Each instruction corresponds to a dedicated hardware operation rather than a microcoded sequence, so the software vocabulary of the machine was discovered from its hardware.

Synthesis and verification

Every module was synthesized with Yosys, technology-mapped to the Sky130HD standard-cell library, and analyzed for timing and power to confirm the design is hardware-realizable rather than only functionally correct in simulation.
