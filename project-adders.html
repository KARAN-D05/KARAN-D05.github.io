High-Performance Adder Architectures

Six 64-bit adder topologies, characterized on identical terms.

Binary addition can be built a dozen ways, and each one trades area, speed, and power differently depending on how the carry chain is computed. This project implements and characterizes six 64-bit adders on identical terms so that trade-off is concrete rather than theoretical: Ripple-Carry (RCA), Carry-Select (CSA), Carry-Bypass (CBA), Carry-Lookahead (CLA), Kogge-Stone (KSA), and Brent-Kung (BKA).

Primary characterization uses the Sky130HD standard-cell library, with Nangate45 used for cross-library comparison, and design-space exploration performed on selected architectures to study how block width trades area against timing within a single topology.

Block-width study

For block-structured topologies (CLA, CSA, CBA), block width is a free parameter: wider blocks reduce the number of stages the carry has to ripple through but grow the logic inside each block. Sweeping this parameter on the Nangate45 library shows the trade-off directly.
